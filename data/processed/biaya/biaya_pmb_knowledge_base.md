> **PANDUAN EKUIVALENSI TERMINOLOGI BIAYA STUDI UII:**
>
> - **Uang Kuliah Awal (UKA)** = **Sumbangan Catur Darma / Dana Catur Darma / UKA**. Biaya ini dibayarkan sekali di awal masuk kuliah berdasarkan peringkat seleksi.
> - **Uang Kuliah Kuartal (UKK)** = **SPP / SPP Tetap & SPP Variabel / Biaya Pendidikan per Kuartal-Semester**. Biaya ini dibayarkan secara rutin per kuartal/semester.

Dokumen resmi ini diekstrak secara otomatis murni dari API Backend Resmi PMB UII (https://pmb.uii.ac.id/programstudi/uka.php & ukk.php).
